Watershed Simulator

Watershed Simulator is a Streamlit web app for SWMM5-style watershed runoff modeling. It lets users configure subcatchment, surface, infiltration, and climate parameters, validates the inputs, generates a SWMM-style model, runs the simulation, and plots the resulting hydrographs with interactive Plotly charts.

The app includes a Low Impact Development module covering eight SWMM5 LID types: bio-retention cells, green roofs, permeable pavement, infiltration trenches, rain barrels, vegetative swales, rain gardens, and rooftop disconnection, with layer-level configuration so users can evaluate green-infrastructure scenarios alongside standard runoff parameters.
